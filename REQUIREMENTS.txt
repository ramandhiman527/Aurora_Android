3. FIREBASE SETUP
--------------------------------------------------------------------------------
To enable phone authentication and secure session states:
1. Create a Firebase project in the Firebase Console (console.firebase.google.com).
2. Register an Android App using your package name: `com.ecommerce.checkout`.
3. Download the `google-services.json` file and place it in the `android/app/` directory.
4. Enable "Phone Sign-In" inside the Firebase Console under:
   Build > Authentication > Sign-in method > Phone (Toggle to Enabled).
5. Configure Android SHA-1/SHA-256 fingerprint in project settings:
   - Generate key: `./gradlew signingReport`
   - Paste SHA-1/SHA-256 key into the Firebase project settings to allow phone verification.

--------------------------------------------------------------------------------
4. RAZORPAY CONFIGURATION
--------------------------------------------------------------------------------
To enable payment gateways and transaction routing:
1. Create a merchant account at Razorpay (dashboard.razorpay.com).
2. Generate API Keys in Test Mode:
   - Navigate to Settings > API Keys > Generate Key.
   - Key ID: Save as `rzp_test_MerchantKey123` (used in startPayment()).
   - Key Secret: Keep safe for backend HMAC validation.
3. Configure Webhook Endpoint:
   - Navigate to Settings > Webhooks > Add New Webhook.
   - Webhook URL: `https://api.premiumfashion.com/v1/orders/webhook-payment`
   - Active Events: Select `payment.authorized` and `order.paid`.
   - Secret: Set a custom webhook signature secret to secure payload reception.

--------------------------------------------------------------------------------
5. ENVIRONMENT VARIABLES
--------------------------------------------------------------------------------
Configure these variables in a secure `.env` file at root or system level:
- `BASE_API_URL` = "https://api.premiumfashion.com/v1"
- `RAZORPAY_KEY_ID` = "rzp_test_MerchantKey123"
- `RAZORPAY_SECRET` = "YOUR_BACKEND_RAZORPAY_SECRET"
- `WEBHOOK_SIGNATURE_SECRET` = "YOUR_WEBHOOK_SIGNATURE_SECRET"

--------------------------------------------------------------------------------
6. EMULATOR SETUP & DEVICE RUN INSTRUCTIONS
--------------------------------------------------------------------------------
To run the project on a local Android Emulator:
1. Open Android Studio > Device Manager.
2. Click "Create Device" and choose a phone specification (e.g. Pixel 7).
3. Select an Android system image (API Level 34 / UpsideDownCake recommended).
4. Launch the virtual device.
5. In your terminal, run the following commands:
   - `$ flutter doctor` (Verify SDK configurations)
   - `$ flutter pub get` (Resolve pub dependencies)
   - `$ flutter run` (Builds app and deploys to the active emulator)

--------------------------------------------------------------------------------
7. INTERACTIVE DEVICE PREVIEW & ADMIN DASHBOARD SERVER (LOCAL MOCK RUNTIME)
--------------------------------------------------------------------------------
If you are running the project locally without full SDK installations, we have provided 
a complete simulated runtime container in `/preview/index.html` (Mobile Emulator preview 
shell) and `/admin-dashboard/dist/index.html` (Admin console).

To launch the local web server:
1. Start the HTTP server in the root of the project:
   `$ python3 -m http.server 8080`
2. Access the simulated environments:
   - Mobile Device Emulator Preview: http://localhost:8080/preview/index.html
   - Administrative Web Console: http://localhost:8080/admin-dashboard/dist/index.html
